# Seguridad

Para proteger tu cuenta, evitá compartir contraseñas, códigos de acceso o datos de sesión al reportar un problema o publicar capturas.

Si descubrís una vulnerabilidad, usá **Security → Advisories → Report a vulnerability** si GitHub muestra esa opción. Si no está disponible, abrí un issue solicitando un canal privado, sin incluir detalles explotables ni credenciales.

La app guarda la sesión y el historial cifrados con Android Keystore, sin copias de seguridad. El repositorio y los instaladores no deben contener sesiones de usuarios ni la clave privada de firma. Las capturas de documentación usan datos de demostración.

La consulta de cuotas depende de un servicio interno que puede cambiar. La app es comunitaria y no está afiliada a OpenAI. Ninguna revisión automática garantiza la ausencia de vulnerabilidades.
